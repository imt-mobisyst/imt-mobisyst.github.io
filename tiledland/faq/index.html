Install

I have some trouble with the dependency to python bind to Cairo librairy (pycairo).

This dependency is not hardly mandatory, but all example and demonstration manipulating PNG image will fail. It is possible to dissable pycairo dependency in the dependancy lists of the pyproject.toml file, and install your local modified version of tiledland (pip install /path/to/your/cloned/tiledland) By doing so, nly SVG rendering will remain available.
